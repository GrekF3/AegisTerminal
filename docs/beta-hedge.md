# Дополнение beta: дневной тренд и серия попыток

Статус на 2026-09-07: непрерывная базовая сессия опубликована в Stable 0.1.9 (та же сборка доступна подписчикам Beta). Удвоение ×2 — отдельное beta-дополнение, оно **ещё не реализовано** и не включено скрыто в базовый режим.

Запрошено пользователем:

- Определять направление внутри текущего дня простым арифметическим анализом. Закрытия дневной свечи не ждать. Предложенная интерпретация: текущая цена относительно цены начала дня.
- Луз — неудачный результат на целевой бирже, не суммарный PnL двух ног и не ошибка API.
- После убыточной сделки удваивать объём следующей, не плечо: ×1 → ×2 → ×4 → ×8 → ×16.
- Лимит лузов задаётся в настройках: целое число от 0, **0 — без ограничения**, по умолчанию 5. Счётчик общий по целевой бирже за одну сессию, по всем монетам вместе. Успешная попытка его не обнуляет. При достижении лимита новые входы блокируются, собственные позиции закрываются; блокировку сбрасывает администратор.
- История ордеров и хеджей.

Реализация базовой сессии:

- Один «Старт» → повторяющиеся циклы до «Стоп», лимита или аварийного состояния. Временная недоступность данных/ликвидности приводит к ожиданию и повтору, не требует нового нажатия Start.
- Направление — текущая цена относительно начала UTC-дня; целевая по тренду, исходная противоположно. Равенство цен разных бирж не гарантируется.
- При достижении ±сохранённого процента от маржи монеты на целевой ноге закрываются обе ноги, затем открывается следующий цикл. Рабочая интерпретация существующего порога: по умолчанию ±98%. Маржа не удваивается.
- Луз учитывается однократно после подтверждённого закрытия по отрицательному target gross price PnL. **Комиссии и funding пока не сверены**, поэтому это предварительный показатель, не окончательный net PnL. Плавающий минус и ошибка API сами по себе счётчик не увеличивают.
- Параллельный мониторинг уже открытых пар работает во время ожидания следующей лимитки. Неизвестное исполнение останавливает новые входы, без слепой повторной заявки.
- Незавершённая сессия после перезапуска требует сверки; новые заявки не отправляются автоматически. Маркер учтённого цикла сохраняется со счётчиком атомарно и защищает от повторного подсчёта при сбое.

Ошибка исполнения второй ноги не равна финансовому убытку завершённой пары: неизвестное исполнение требует сверки, а не удвоения/повторной заявки. Процесс с открытой позицией нельзя выключать вместо аварийной остановки новых запусков. Предварительный PnL текущего ядра нельзя использовать как окончательный результат для ×2.

История реализована локально: `trade-history/<hash пользователя>/<hash хеджа>.json`, атомарная перезапись состояния хеджа и его ордеров, без дубликатов при перечитывании. Доступ через авторизованный IPC; поиск, страницы по 25 записей, разворачивание ордеров и причины ошибки в интерфейсе. Секреты отфильтрованы. Старые циклы, которых нет в этом хранилище, автоматически не восстанавливаются из биржевой истории. Финальный PnL остаётся неизвестным либо явно предварительным.
