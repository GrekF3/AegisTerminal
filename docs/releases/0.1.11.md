# 0.1.11 — локальная остановка без подключения к бирже

Собрана локально 2026-09-07. В production-каналы не опубликована.

- «Я закрою позиции сам» немедленно переводит бота в `stopped / active=false`, без чтения статусов, отмены ордеров и закрытия позиций. Режим работает при отключённом Undetectable, недоступном API и после перезапуска, даже если credentials изменились.
- Ручная остановка доступна во время зависшего автоматического закрытия. Старый ответ/ошибка не возвращает окно прогресса и не меняет остановленное состояние.
- Последующие торговые действия, мониторинг и сверка прекращаются. Уже переданные в адаптер операции могут завершиться; пришедшие подтверждения сохраняются, без отправки следующей заявки. Начало новой сессии ждёт завершения таких запросов, сама остановка не ждёт.
- Позиции и заявки остаются на биржах. Их статусы не подменяются на CANCELED/FILLED, закрытый раунд и прибыль не выдумываются. Полный журнал ручной остановки сохраняется в каталоге профиля `manual-stops`; история отмечает ручное управление.
- Поздние события прежней сессии не перезаписывают журнал новой. Лимит убытков и административный сброс сохраняются.

Проверка: 229 backend-тестов, TypeScript, production web build, Windows-сборка; браузерные сценарии при 1280×850 и 420×780. Проверены отсутствие подключения, зависшие preparation/place/status/cancel/closePlan, переключение с market-stop, поздний успешный ответ и поздняя ошибка. UI-кнопки доступны, переполнения нет.

По запросу пользователя локальный процесс 0.1.10 остановлен; сохранённая локальная сессия переведена в ручное управление с архивированием полного журнала. Исправленная локальная 0.1.11 запущена в окне `Hedge LBank · Local`. Торговых команд для отмены или закрытия реальных позиций не отправлялось.
