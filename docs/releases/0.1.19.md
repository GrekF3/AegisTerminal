# Hedge LBank 0.1.19

## Что изменилось

- Исправлена гонка LBank при повторном закрытии: новая сверка начинается только после остановки старой очереди запросов.
- Перед повторными действиями приложение читает свежие позиции и все открытые заявки обеих бирж. Если по символам сессии везде пусто, закрытие подтверждается без лишних торговых запросов.
- После подтверждённого закрытия старый журнал архивируется, интерфейс сбрасывается в исходное состояние и показывает понятное сообщение об успешной очистке.
- Старая ошибка закрытия больше не появляется заново при каждом перезапуске. Незавершённая сессия остаётся заблокированной до новой сверки, но без повторного красного уведомления.
- Добавлен часовой публичный сканер ликвидности и задержки сведения для LBank ↔ MEXC и LBank ↔ Binance. Для монет на всех трёх биржах эталоном движения служит Binance.

## Проверка

- Отдельно проверены пустые позиции/ордера без торговых записей, порядок LBank stop-fence и восстановление старой ошибки OKX `51169`.
- Полный backend-набор, TypeScript, production web build и Windows NSIS проверяются перед публикацией.

Сканер использует только публичные рыночные данные и не имеет доступа к торговым ключам.
