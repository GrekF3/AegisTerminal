# Stable 0.1.9 — Windows x64

Опубликовано 2026-09-07 в каналы Stable и Beta. Stable — значение по умолчанию для нового профиля; явно сохранённый Beta не переписывается. Установленное приложение и текущий локальный процесс не перезапускались. Незавершённые торговые журналы не удалялись и не архивировались.

## Состав

- Непрерывный хедж: целевая сторона по текущему UTC-дню, исходная противоположно; общий бюджет поровну по монетам, индивидуальные плечи, общий лимит лузов с 0 = без ограничения.
- Переставляемая исходная лимитка; вторая maker-заявка до 1,5 секунды при поддержке обеих бирж, затем MARKET подтверждённого остатка.
- Полный цикл LBank Undetectable · CDP с ручным подключением, удержанием ответов CDP и запретом повторной отправки при неизвестном результате.
- Исторические объёмы LBank трактуются как базовый актив, текущие — как контракты. Завершённый ордер сверяется по точным ID и символу; переход в историю допускает до 15 секунд повторного чтения.
- TP/SL от фактической входной маржи целевой позиции; короткое ожидание PnL не считается ошибкой.
- MARKET Stop с подтверждённым прогрессом. «Я закрою позиции сам» не создаёт экран закрытия и не отправляет новых закрывающих заявок.

## Проверка

- 167 backend-тестов, typecheck, production static export и Windows NSIS build — успешно.
- Многомонетная регрессия проходит через LBank SDK: BTC/ETH/BNB одновременно, закрытие и повторное открытие ETH без потери BTC/BNB, затем закрытие собственных объёмов без дублей.
- Реальные завершённые BTC/ETH ордера прочитаны без отправки торговых команд. Новых реальных ордеров при проверке не отправлялось.
- Stop проверен в изолированном браузерном bridge на широком и узком окне. Упакованный ASAR запускается с отдельным временным профилем: preload, локальный file-протокол, DOM авторизации и canvas доступны, активного хеджа нет. Проверка updater в этом smoke изолирована; это не end-to-end тест установки.
- Все 34 runtime-файла Electron в ASAR совпадают с исходниками. Fixtures, тесты, диагностические скрипты и пользовательские ключи/настройки в пакет не входят.
- Серверные SHA-512 обеих копий установщика проверены до атомарной замены latest.yml. Предыдущие манифесты и установщики сохранены для отката.
- Публичная проверка после публикации успешна: оба latest.yml указывают 0.1.9, размер/HTTP Range/blockmap совпадают; установщик Stable полностью скачан по HTTPS и его SHA-512 совпадает с локальным файлом.

## Ограничения

Предварительно размещённых биржевых TP/SL нет: пороги контролирует работающее приложение, закрытие — MARKET. Удвоение маржи ×2 не реализовано. Приватный SDK LBank может меняться; локальные тесты не подтверждают все возможные исходы на живой бирже. Незавершённая сессия после перезапуска требует сверки, а не сброса журнала. Установщик не имеет Authenticode-подписи. macOS-сборка в этом выпуске не создавалась.
