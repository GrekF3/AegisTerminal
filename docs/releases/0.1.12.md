# 0.1.12 — остановка бота независимо от закрытия позиций

Локальная версия от 2026-09-07. В production-каналы не опубликована.

В 0.1.11 немедленная локальная остановка работала только после выбора «Я закрою позиции сам». Обычный market-stop при неподтверждённом LBank-запросе продолжал показывать активную аварийную сессию. Верхняя кнопка открывала диалог без остановки стратегии.

- Верхняя кнопка «Стоп» сначала прекращает стратегию локально, затем открывает выбор дальнейшего действия. Для этого не нужны соединение с биржей, авторизация или Undetectable.
- Работа бота и закрытие его позиций имеют независимые состояния. Ошибка закрытия не меняет `botStopped=true / active=false` и не препятствует выходу из диалога.
- Автоматическое закрытие запускается явным действием. Неизвестный исход ордера сохраняется в журнале; повторный вход не отправляется. Ожидание истории может продолжать только ранее запрошенное закрытие.
- «Я закрою позиции сам» прерывает ожидание и запрещает последующие биржевые действия. Уже отправленный запрос может завершиться; поздний ответ записывается без следующей заявки.
- Остановка сохраняется при перезапуске. Повторное явное закрытие после ручного управления использует отдельную сессию только для закрытия, исходные идентификаторы ордеров и проверку исходного подключения.

По текущему запросу пользователя оба запущенных экземпляра приложения закрыты; журналы установленного и локального профилей переведены в остановленное состояние с сохранением архивов. Реальные заявки для отмены или закрытия позиций при разработке не отправлялись.

Проверено: 244 backend-теста; TypeScript; production static export; 17 сценариев в Chromium с изолированным bridge, включая зависшее закрытие, позднюю ошибку, повторное открытие диалога, ручное управление и восстановление. Шесть проверок расположения элементов при ширине 1280 и 420 px прошли без переполнения. Повторная остановка уже закрытой сессии не создаёт новый запрет запуска; лимит убытков сохраняется отдельно.

Windows-установщик `Hedge LBank Setup 0.1.12.exe`: 95 576 619 байт. Проверены SHA-512, manifest/blockmap, совпадение всех 36 runtime-модулей и 70 статических файлов интерфейса с локальной сборкой, отсутствие credentials и тестовых данных в пакете. Готовый ASAR запущен в отдельном временном профиле: preload работает, экран входа загружен, торговля неактивна. Пользовательские экземпляры остаются закрытыми.
