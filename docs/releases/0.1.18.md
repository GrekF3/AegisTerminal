# Hedge LBank 0.1.18

## Что изменилось

- LBank Futures переведён на проверенный браузерный SDK с точными единицами контрактов, режимами Cross/Isolated и подтверждением результата через приватный поток и повторное чтение состояния.
- Запись реального трафика LBank подтвердила открытие, закрытие, Post-Only, плечо, TP/SL и переключение режима маржи. Диагностический recorder удаляет авторизационные данные перед сохранением.
- Закрытие стало идемпотентным: отсутствие позиции подтверждается свежим снимком, неизвестный результат запроса не приводит к повторной заявке.
- Добавлена нормализация проверенных ошибок бирж, включая LBank и OKX `51169`; неизвестные коды остаются безопасно неопределёнными.
- Защитные TP/SL проверяются по стороне, объёму, типу триггера и серверным идентификаторам. Неизвестный статус не считается активной защитой.
- Основной сценарий подготовлен для LBank ↔ Bybit с восстановлением сессии после перезапуска и контролем обеих ног.

## Проверка

- Backend: 323 теста.
- TypeScript: без ошибок.
- Production web build: успешно.
- Windows NSIS: локальная проверка состава, версии и SHA-512 обязательна перед публикацией.

Живая торговля не запускается сборкой или установкой обновления. Первую проверку новой версии следует выполнять на минимальном размере позиции.
