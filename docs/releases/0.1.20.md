# Hedge LBank 0.1.20

## Что изменилось

- LBank Futures WebSocket теперь обрабатывает не только стартовый массив тикеров, но и последующие одиночные обновления `z=4`.
- Рыночные цены LBank остаются свежими между запросами и больше не переходят без причины на медленный HTTP-резерв через десять секунд.
- Сканер ликвидности использует живые LBank-обновления для измерения активности и задержки сведения с Binance/MEXC.
- Глубина публичного стакана LBank корректно читает поле `volume`; отсутствие или снятие инструмента не превращается в нулевой спред.

## Проверка

- Добавлены тесты стартового тикер-снимка, одиночного live-update и объектного формата LBank depth.
- Живой smoke-тест подтвердил повторные изменения BTC, ETH и SOL примерно раз в секунду и получение стаканов всех трёх бирж.

Сканер и тесты используют только публичные рыночные данные.
