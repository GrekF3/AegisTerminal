# LBank Impulse

Отдельный локальный терминал для одной выбранной монеты. Публичные котировки и стаканы приходят по WebSocket LBank, Binance и MEXC; реальные команды LBank выполняет существующий SDK внутри явно выбранной Futures-вкладки Undetectable.

## Запуск

1. Запустите Undetectable, нужный профиль и одну вкладку LBank Futures.
2. Откройте `run-lbank-impulse.cmd` или выполните `npm run impulse`.
3. Выберите профиль и нажмите «Подключить». После подключения поле монеты получает актуальный список LBank Futures: можно искать по `BTC` или полному `BTCUSDT`.
4. Выберите монету, откройте `⚙ Настройки`, проверьте эффективные параметры и нажмите Start.

Окно настроек имеет два уровня. «Глобальные» — базовые значения для всех контрактов. «Для текущей монеты» — только отмеченные переопределения; остальные поля продолжают наследовать глобальные значения. Профиль, последняя монета, режим, оба уровня параметров и список переопределений сохраняются локально и восстанавливаются при следующем запуске. Старый плоский файл настроек автоматически переносится в профиль последней монеты, поэтому введённые пользователем значения не теряются и не становятся случайными глобальными значениями.

Порог по умолчанию — `0,04%`; для ZECUSDT сохранённое ранее значение `0,03%` остаётся переопределением монеты. Режим `Paper Test` предназначен только для проверки полного жизненного цикла: после 250 мс с новым стаканом он подтверждает тестовый maker-fill. Цены, стаканы, Post-Only-уровень и ограничения выхода остаются рыночными, а тестовый fill явно помечается в журнале. Комиссии, проскальзывание и расчётный net PnL показываются справочно и не блокируют вход ни в Paper, ни в Live. Для обычного входа сохраняется требование положительного остаточного лага в сторону сигнала; `Paper Test` может пройти цикл и без него. Красная метка `LIVE` означает, что следующий Start может отправлять реальные заявки. `PAUSE` запрещает новые входы, но продолжает контролировать открытую позицию. `STOP & FLAT` отменяет точную входную заявку, закрывает подтверждённый объём reduce-only MARKET и удаляет серверную защиту после доказанного flat.

## Обязательные ограничения

- Одна монета, одна заявка или позиция одновременно.
- Binance является ведущей, если контракт существует; иначе используется MEXC.
- Вход — Post-Only внутри спреда; время жизни заявки настраивается глобально или для монеты.
- Live требует свежих данных, персональных комиссий, пустой позиции/списка ордеров и общей блокировки с основным Hedge LBank.
- Неизвестный результат write-запроса сохраняется в журнале и блокирует повтор до сверки.
- Откат больше не считается разворотом, пока ведущая цена сначала не прошла заданное расстояние в плюс. По умолчанию трейлинг активируется после `0,03%`, минимальное удержание — `500 мс`, откат — `0,03%` с подтверждением `300 мс`.
- Штатный трейлинг по умолчанию закрывает только при неотрицательном исполнимом net после maker/taker-комиссий и текущего стакана LBank. Этот порог настраивается и не влияет на входной фильтр.
- Аварийные выходы не отключаются: adverse-движение `0,08%`, максимум `10 секунд`, Stop или устаревшие потоки. Все значения, кроме ограничений свежести данных, доступны в настройках.

Paper использует те же сигналы. Fill считается только когда новая версия стакана показала достаточный встречный объём минимум на один tick сквозь цену заявки; одно касание не считается исполнением.

Блок «Сигнал и позиция» показывает PnL открытой позиции, возраст удержания, состояние трейлинга, лучшее движение, откат, исполнимый exit net и статистику текущей сессии. Счётчики обновляются только по закрытиям с известным результатом и сохраняются в состоянии приложения; `Pause`/`Start` без изменения параметров продолжает текущую сессию, а `STOP & FLAT` или изменение любого эффективного параметра начинает новую.

Журнал можно выделять и копировать через `Ctrl+C` или контекстное меню. Автопрокрутка работает только когда просмотр находится внизу: ручная прокрутка вверх или выделение текста удерживает текущую позицию, а возврат к последней строке снова включает follow-tail. Кнопка `↓ К последним` возвращает журнал в конец вручную.

## Журнал и replay

Состояние восстановления, торговый журнал и записи рынка находятся в `%APPDATA%\Hedge LBank\impulse`. `journal.jsonl` хранит намерения, точные ID, исполнения, защиту и закрытия отдельно от настроек. Каждый Start создаёт отдельный файл в `replays`; он не содержит cookies или API-ключей.

Проверить сохранённую сессию можно командой:

```powershell
node tools/lbank-impulse/replay.cjs "C:\path\to\replay.jsonl"
```

Отчёт пересчитывает сигналы по порядку кадров без look-ahead и выводит число сигналов, fill rate, gross/net PnL и максимальное время удержания.
