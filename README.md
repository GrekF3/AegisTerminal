# Aegis Terminal

A desktop trading terminal for monitoring markets and coordinating hedged positions across multiple exchanges.

## Features

- Multi-exchange market data adapters
- Position, balance, and fee monitoring
- Automated and manual hedge workflows
- Electron desktop runtime with a Next.js interface
- Paper-trading and backend test suites

## Run locally

```bash
npm install
npm run dev:desktop
```

Use test accounts or paper mode before connecting exchange credentials.
